## Para rodar o Virtual Enviroment:

# Caso estiver em Trabalho prático 2, entre na pasta src
cd ./src 

# Abra o cmd e digite o seguinte comando para ativar o virtual enviroment
venv\Scripts\activate.bat

# Caso apareça (venv) C:\IA\Trabalho_Pratico_2\src> no terminal, significa que deu certo e você já pode instalar as bibliotecas do projeto ou rodar o projeto

---

# Caso ainda não tenha um virtual enviroment, digite:
python -m venv venv

venv\Scripts\activate.bat
